# Сборка и публикация атласа

Отдельный статический проект для GitHub Pages: книги Курпатова как начальный слой, их темы, исследовательские эпизоды, мыслители, названные работы и библиографические записи. Сравнение двух книг показывает общие карточки и отдельные подтверждения каждого текста.

В пакете 50 позиций корпуса, 4 698 узлов и 11 441 исходных связей. Дополнительные рёбра книжной навигации являются представлением адресов, не входят в исходный граф и не означают доказанное влияние. Переиздания и гостевые тексты отмечены в интерфейсе. Числа относятся к разметке корпуса, а не к полной научной библиографии автора.

Версия 5 добавляет общий поиск по карточкам и сохранённым цитатным основаниям. Поиск не зависит от фильтров текущего графа: результат содержит книгу, страницу или абзац и прямую ссылку на источник. Формы «любовь», «любви», «любовью» сопоставляются; «любой» и «любование» не считаются совпадением. Это поиск по разметке, а не полнотекстовый поиск всех книг. Новый запрос начинается сверху; дополнительные результаты загружаются кнопкой «Показать ещё».

«Сбросить всё» очищает поисковые поля, ограничения, выбор цепочки и книги и возвращает начальную карту 50 книг. Дополнительные фильтры сворачиваются. Название текущей книги или цепочки видно над графом. Закрытые разделы создаются при первом открытии, ввод обрабатывается с короткой задержкой, перерисовки объединяются в кадр браузера. Полный состав узлов и связей сохраняется.

## Локальный просмотр

Откройте `site/index.html` в браузере. Приложение работает без сервера и внешних библиотек. Для просмотра в HTTP-контексте:

```sh
python -m http.server 8000 --directory site --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/`.

## Обновление и проверка

Python 3, только стандартная библиотека:

```sh
python scripts/build_site.py
python scripts/check_site.py
```

`site/atlas-data.json` — обычный полный аналитический JSON. Встроенные данные в HTML используют таблицу повторяющихся ссылок; при загрузке восстанавливается тот же объект. Сборка проверяет обратимость этого преобразования. Источники в `site/sources/` содержат цитатные опоры, используемые разметкой.

## Публикация отдельного проекта

1. Репозиторий проекта: [BurangulovRuslan/discourse_management](https://github.com/BurangulovRuslan/discourse_management).
2. Загрузите содержимое **этой папки** через Git в ветку `main`, включая скрытую папку `.github`. Выполните из этой папки:

```sh
git init -b main
git add .
git commit -m "Prepare book-centred discourse atlas"
git remote add origin https://github.com/BurangulovRuslan/discourse_management.git
git push -u origin main
```

Если локальный Git уже инициализирован, используйте существующую ветку `main` и настроенный remote `origin`.

Самый крупный файл — аналитический JSON, около 60 MiB. Поэтому для загрузки проекта используется Git: браузерная загрузка ограничена 25 MiB, а файлы пакета укладываются в предел 100 MiB для обычного Git-репозитория. [Официальные ограничения GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

3. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Во вкладке **Actions** запустите **Publish discourse atlas → Run workflow**, если публикация не началась после push.
5. После успешного workflow адрес сайта будет показан в **Settings → Pages**. Для проекта он имеет вид `https://burangulovruslan.github.io/discourse_management/`.

Workflow собирает и проверяет пакет перед отправкой каталога `site` в Pages. Все внутренние ссылки относительные и работают в подкаталоге репозитория. В проект не включены исходные PDF/FB2/DOC/RTF и полные извлечения; опубликованный материал — аналитика и цитатные опоры.

Основание конфигурации: [GitHub: custom Pages workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [GitHub: creating a Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Ссылки на книги и сравнение

Книга: `index.html#book=B003&type=overview`.

Сравнение: `index.html#compare=B003,B004&type=experiment`.

Идентификаторы книг сохранены во всех экспортах. Кнопка «Ссылка на книги графа» создаёт ссылку на выбранный книжный контекст. Для цитаты используется `sources/B003.html#PDF_p_174`; адрес относится к физической странице локального PDF.

## Состав

- `src/` — редактируемая оболочка и навигация.
- `scripts/` — воспроизводимая сборка и проверки.
- `site/index.html` — самостоятельное приложение.
- `site/atlas-data.json`, `site/kurpatov.graphml`, `site/research-register.csv` — аналитические экспорты.
- `site/analytical-report.html` — отчёт для чтения и печати.
- `site/build-manifest.json` — размеры и SHA-256 файлов.
- `validation.json` — результат проверки относительных ссылок, адресов и состава пакета.

Подготовка проекта не создаёт удалённый репозиторий и не публикует сайт. Аналитические реконструкции, литературные отсылки, библиографические записи и эмпирические исследования различаются по типу и статусу; присутствие имени не означает принятия всей теории.


## Публичный интерфейс

В сборке с `publication_mode=public` вкладка «Корпус и метод» удаляется из навигации и не открывается через приложение. Локальный исследовательский атлас сохраняет эту вкладку. Адресные страницы цитат в `site/sources/` продолжают работать.
