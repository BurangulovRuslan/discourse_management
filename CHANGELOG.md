# Версия 5 · 8 октября 2026

Общий поиск по карточкам и сохранённым цитатным основаниям выдаёт прямые адреса страниц и абзацев. Поиск охватывает разметку всех 50 книг независимо от текущей карты. Это не полнотекстовый индекс книг. Формы «любовь», «любви» и «любовью» сопоставляются; «любой» и «любование» исключены. Для «любовь» доступно 53 фрагмента. Цитатные адреса показаны первыми, подсветка сохраняет исходный текст.

«Сбросить всё» очищает все поиски, ограничения и выбор цепочки и возвращает начальные 50 книг. Отложенный запрос отменяется; новая выдача начинается сверху. Над графом показана текущая книга или цепочка. Внутренний поиск графа сохраняет его контекст и снимает прежний фокус.

Интерфейс получил более компактную шапку, сворачиваемые дополнительные фильтры, ограниченную высоту поисковой выдачи и удобные элементы управления на мобильных экранах. Подписи плотного графа появляются при выборе, наведении или достаточном масштабе; состав узлов и связей не сокращён.

Закрытые разделы создаются при открытии. Повторные перерисовки объединяются в кадр, обработка ввода задержана на 110–130 мс. Слова для поиска кэшируются после первого запроса.

Локальный headless Chrome, 1440×1000, медиана трёх запусков: готовность первого кадра 378→287 мс; открытие полного графа 82→64 мс. Стартовый DOM 42419→649 элементов. Прямой поиск без задержки ввода: первый запрос 125 мс, повторный 13 мс. Это измерения на данном компьютере, без сетевой загрузки. Уменьшение памяти не заявляется.

Аналитические данные совпадают с проверенным снимком v4, кроме поля версии: 4 698 узлов, 11 441 связей, 50 позиций корпуса. Сохранены ID рёбер, книжные адреса, 489 карточек эпизодов и 547 вариантов. Проверены точные цитаты и адреса, полный состав разделов, сброс, книжные категории, мобильный интерфейс и HTTP-ссылки в подкаталоге репозитория.

Отдельный проект содержит GitHub Actions, воспроизводимую сборку стандартным Python и инструкцию публикации. Оригинальные книги и полные извлечения в пакет не включены.

Публикационная сборка: вкладка «Корпус и метод» скрыта только в публичном приложении; адресные цитатные страницы сохранены. Главный README содержит краткое описание продукта и руководство из шести действий. Технические инструкции вынесены в DEPLOYMENT.md.
