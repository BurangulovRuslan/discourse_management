# Атлас дискурса Андрея Курпатова

Атлас помогает исследовать, как в книгах Андрея Курпатова связаны представления о мышлении, человеке и действии. Корпус объединяет **50 книг, 4698 узлов, 11441 связь и 5370 уникальных размеченных цитатных фрагментов**.

Основной вход — **Explorer** в `site/index.html`: новый интерфейс на Angular с живой ризоматической картой, библиотекой, поиском и сохранёнными идеями. **Legacy** в `site/legacy.html` сохраняет полный прежний исследовательский атлас и его инструменты. Между версиями можно переключаться: ссылка на Legacy находится в боковом меню Explorer, обратная ссылка — вверху Legacy. Старый адрес `atlas.html` открывает Legacy с сохранением параметров ссылки.

## Как пользоваться Explorer

1. **Начните с карты или библиотеки.** Выберите тему на «Карте смыслов» либо откройте одну из 50 книг в «Библиотеке». В библиотеке доступны поиск по названию и фильтр периода.
2. **Исследуйте карточку.** Нажатие на узел открывает его описание, цитатные опоры и соседние узлы из реальных данных. Цитата ведёт на страницу источника с адресом конкретного фрагмента. Если первоначальная загрузка не содержит примеров для этого узла, нажмите «Показать цитатные опоры».
3. **Найдите вопрос.** Кнопка «Поиск по атласу» или `Ctrl+K` / `⌘+K` открывает поиск по карточкам и всем 5370 цитатным фрагментам. Введите от двух символов: например, «мышление» или фрагмент цитаты. Поиск не различает регистр и «е/ё»; для более широкого результата используйте короткую основу слова. Полный индекс цитат подгружается при обращении к поиску.
4. **Соберите маршрут.** Нажмите «Сохранить идею», чтобы вернуться к узлу из раздела «Сохранённое». Коллекция хранится в этом браузере на этом устройстве.
5. **Настройте обзор.** Переключайте слои «Темы», «Понятия», «Авторы» и «Книги», меняйте масштаб, приостанавливайте движение или сбрасывайте вид карты. Под картой есть доступный список показанных узлов.

Ризоматическая композиция Explorer — **художественный обзор точек входа**: на экране показана небольшая выборка реальных узлов. Декоративные линии и положение точек служат визуальной навигации. Точная топология доступна в полном графе Legacy; раздел «Связанные идеи» в карточке Explorer также использует реальные связи корпуса.

## Когда открыть Legacy

Legacy содержит сравнение двух книг с отдельными цитатами каждой, цепочки аргументации, эволюцию понятий, развитие по годам, реестр исследований, авторов и работ, подробное кодирование и полный граф без ограничения числа узлов.

В его графе сплошные связи обозначают описания или отсылки в тексте, пунктирные — аналитическую реконструкцию. Стрелки показывают порядок рассуждения или сопоставления. Наличие связи само по себе не доказывает причинность. Ограничения интерпретации, различия авторских голосов и оговорки исследований сохранены в исходных карточках.

## Данные и источники

Единый аналитический снимок — `site/atlas-data.json`. Данные для Explorer генерируются из него без изменения названий узлов и текста цитат:

- `site/explorer-data.json` — все книги, узлы и связи, краткие описания и выборка цитат для быстрого первого открытия; размер менее 3 MB.
- `site/explorer-search.json` — полный индекс всех 5370 цитатных фрагментов с адресами источников, авторством и связанными узлами; загружается по запросу.
- `site/sources/` — страницы размеченных цитатных опор с якорями страниц и абзацев. Они содержат использованные фрагменты; полные книги в публичный пакет не включены. Для OCR-источников возможны ошибки распознавания, а адрес PDF относится к физической странице локального издания.
- `site/kurpatov.graphml`, `site/research-register.csv`, `site/analytical-report.html` — полный граф, табличный реестр и отчёт для чтения.

Описания в Explorer сокращены для обзора; полный контекст доступен в Legacy и аналитическом экспорте. Счётчики отражают разметку корпуса, а не частоту слов, силу доказательств или число независимых исследований. Переиздания могут повторять один материал.

## Локальная сборка и просмотр

Нужны **Python 3.10+**, **Node.js ветки 22 версии 22.14 или новее** и npm. Фронтенд использует **Angular 20.3**, standalone-компоненты и zoneless change detection. Отдельный сервер приложений или база данных для опубликованного сайта не требуются.

Из корня репозитория выполните по порядку:

```sh
python scripts/build_site.py
cd frontend
npm ci
npm run build
cd ..
python scripts/build_site.py --manifest
python scripts/check_site.py
python -m http.server 8000 --directory site
```

Откройте [Explorer на localhost:8000](http://localhost:8000/) или [Legacy](http://localhost:8000/legacy.html). На системах, где Python вызывается как `python3`, замените `python` в командах. Просматривайте Explorer через HTTP: он загружает JSON из каталога сайта.

Первая команда создаёт Legacy, страницы источников и компактные экспорты. `npm run build` собирает Angular и публикует новый `site/index.html` и файлы в `site/assets/explorer/`. Затем обновляется манифест и выполняется проверка ссылок, якорей, топологии, цитат и отсутствия приватных путей и полных книг. Результат записывается в `validation.json`.

Для разработки с автоматическим обновлением интерфейса:

```sh
python scripts/build_site.py
cd frontend
npm ci
npm start
```

Откройте [localhost:4200](http://localhost:4200/). Сначала генерируются данные и Legacy, затем Angular dev server обслуживает их вместе с интерфейсом. Команда `npm start` предназначена для разработки; готовый публикуемый сайт создаётся командой `npm run build`.

GitHub Actions собирает и проверяет сайт для pull request в `main`. После изменений в `main` он также публикует каталог `site/` через GitHub Pages. Workflow можно запустить вручную; публикация разрешена только для ветки `main`.
