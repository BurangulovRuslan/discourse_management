# Атлас дискурса Андрея Курпатова

Атлас помогает исследовать, как в книгах Андрея Курпатова связаны представления о мышлении, человеке и действии. Корпус объединяет **50 книг, 4698 узлов, 11441 связь и 5370 уникальных размеченных цитатных фрагментов**.

Основной вход — **Explorer** в `site/index.html`: интерфейс на Angular с единым объёмным графом **всех 4698 узлов и 11441 реальной связи**. При приближении узлы раскрываются в журнальные обложки с полными названиями и уникальным процедурным ASCII-артом. Тёмный архив, холодные нейронные ветви и золотые маршруты выбранного материала объединяют карту с полными досье. **Legacy** в `site/legacy.html` сохраняет прежний исследовательский атлас и его инструменты. Между версиями можно переключаться: ссылка на Legacy находится в Explorer, обратная ссылка — вверху Legacy. Старый адрес `atlas.html` открывает Legacy с сохранением параметров ссылки.

## Как пользоваться Explorer

1. **Исследуйте карту.** Первый экран показывает читаемую окрестность обложек; все остальные продолжаются в глубину того же графа. Перетаскивайте, чтобы вращать пространство; Shift + перетаскивание перемещает камеру, колёсико или кнопки меняют масштаб. «Вся карта» показывает полный корпус, «Читать карту» возвращает к читаемому масштабу. Поддерживаются сенсорные жесты и клавиатура: стрелки, `+`, `−`, `0`, `Tab` и `Enter`.
2. **Выберите обложку.** Камера плавно подлетает к узлу, а его пространственная окрестность упруго раздвигается для чтения. Обложки находятся внутри графа: вращение камеры меняет перспективу и взаимное положение, приближение меняет их размер. На большом экране подробно раскрывается до восьми соседей, на телефоне — до четырёх; стрелки перелистывают крупные обложки. Все связи выбранного узла сохраняются в графе, включая соседей вне текущей группы чтения. Выбор соседней обложки продолжает путешествие. Кнопка «Читать материал» открывает журнальное досье с исходным описанием, тематическими разделами, цитатами и адресами источников.
3. **Найдите вопрос.** Поиск или `Ctrl+K` / `⌘+K` находит материалы и цитаты среди всех 5370 фрагментов. Он учитывает русские словоформы, «е/ё», опечатки и контролируемые расширения близких понятий. Например, «системным мышлением», «мышлние» или «перцепция». Результаты ранжируются, совпадения подсвечены, причина поиска показана. Полный индекс цитат подгружается при обращении к поиску или открытии материала и строится порциями, чтобы не останавливать интерфейс.
4. **Продолжите по связи.** Выбор в поиске и галерее досье тоже переносит к узлу на карте. Кнопка браузера «Назад» возвращает к предыдущей остановке; закрытие досье сохраняет текущую окрестность. Адрес `#node=ID` открывает узел на карте, `#node=ID&view=article` — его полный материал. Сохраняйте интересующие узлы в коллекцию этого браузера.

Карта использует **одно трёхмерное пространство без отдельных слоёв по типам узлов**. Исходные координаты заранее рассчитаны D3 Force 3D по всему реальному графу; Three.js отображает сеть через WebGL. При выборе узла рассчитывается локальная органичная раскладка в мировых XYZ-координатах с разной глубиной. Узлы, обложки и концы всех их связей плавно перемещаются согласованно; при смене фокуса прежняя окрестность возвращается к исходной геометрии. Поворот камеры не перестраивает эту раскладку. Аналитические экспорты не меняются. Фоновые линии приглушены; все связи выбранного узла отмечены, а текущая группа чтения выделена ярче. Световые частицы следуют тем же пространственным маршрутам. Движение можно поставить на паузу; оно автоматически останавливается при чтении материала, в скрытой вкладке и при системном предпочтении уменьшенного движения. Положение и длина линии помогают ориентироваться и не являются самостоятельной мерой смысловой близости, хронологии или силы доказательств.

Счётчик узла различает связи и уникальных соседей: между двумя материалами может быть несколько размеченных отношений. Например, у B045 — 613 связей и 611 соседей. Ограничение числа крупных обложек на одной странице не ограничивает граф: весь корпус содержит 11 441 связь.

Поиск работает **локально и без платного API**: MiniSearch (MIT), русская обработка слов по алгоритму Snowball и небольшой явно размеченный словарь синонимов и связанных понятий. Это ранжированный полнотекстовый поиск с расширением запроса, а не нейросетевая модель: он не генерирует ответы и не утверждает, что понимает любой вопрос. Точные совпадения имеют приоритет над близкими понятиями. Исходные цитаты и авторство не изменяются.

Тексты досье разделены на абзацы: сохранены границы элементов разметки, а длинные пояснения разбиты по завершённым предложениям. В цитатах восстановлены имеющиеся пустые строки и убраны разрывы строк OCR внутри абзаца. Оригинальные `description`, `text`, `excerpt`, авторство и адреса источников сохранены; проверка сравнивает полный текст до и после форматирования.

## Когда открыть Legacy

Legacy содержит сравнение двух книг с отдельными цитатами каждой, цепочки аргументации, эволюцию понятий, развитие по годам, реестр исследований, авторов и работ, подробное кодирование и полный граф без ограничения числа узлов.

На карте сплошные связи обозначают описания или отсылки в тексте, пунктирные — аналитическую реконструкцию. Направление связи и её точная формулировка доступны в материалах и Legacy. Наличие связи само по себе не доказывает причинность. Ограничения интерпретации, различия авторских голосов и оговорки исследований сохранены в досье.

## Данные и источники

Единый аналитический снимок — `site/atlas-data.json`. Данные для Explorer генерируются из него без изменения названий узлов и текста цитат:

- `site/explorer-data.json` — все книги, узлы и связи, координаты реальной карты, степени узлов, краткие описания и выборка цитат для быстрого первого открытия; размер менее 3.5 MB.
- `site/explorer-dossiers.json` — полные описания и содержательные разделы всех 4698 узлов, исходные семантические поля без повторения цитат и формулировки всех 11441 связей; загружается по запросу.
- `site/explorer-search.json` — полный индекс всех 5370 цитатных фрагментов с адресами источников, авторством и связанными узлами; загружается по запросу.
- `site/sources/` — страницы размеченных цитатных опор с якорями страниц и абзацев. Они содержат использованные фрагменты; полные книги в публичный пакет не включены. Для OCR-источников возможны ошибки распознавания, а адрес PDF относится к физической странице локального издания.
- `site/kurpatov.graphml`, `site/research-register.csv`, `site/analytical-report.html` — полный граф, табличный реестр и отчёт для чтения.

На карте используется короткое представление материала; при открытии досье загружается полный исходный контекст. Счётчики отражают разметку корпуса, а не частоту слов, силу доказательств или число независимых исследований. Переиздания могут повторять один материал.

## Локальная сборка и просмотр

Нужны **Python 3.10+**, **Node.js ветки 22 версии 22.14 или новее** и npm. Фронтенд использует **Angular 20.3**, standalone-компоненты и zoneless change detection. Отдельный сервер приложений или база данных для опубликованного сайта не требуются.

Из корня репозитория выполните по порядку:

```sh
python scripts/build_site.py
cd frontend
npm ci
npm run build
cd ..
python scripts/build_site.py --manifest
python scripts/check_site.py
python -m http.server 8000 --directory site
```

Откройте [Explorer на localhost:8000](http://localhost:8000/) или [Legacy](http://localhost:8000/legacy.html). На системах, где Python вызывается как `python3`, замените `python` в командах. Просматривайте Explorer через HTTP: он загружает JSON из каталога сайта.

Первая команда создаёт Legacy, страницы источников и экспорты. `npm run build` рассчитывает координаты полного графа, собирает Angular и публикует новый `site/index.html` и файлы в `site/assets/explorer/`. Расчёт использует закреплённую версию D3 Force 3D, детерминированные начальные координаты и все исходные связи. При неизменной топологии готовая раскладка используется повторно; `npm run layout -- --force` пересчитывает её. Затем обновляется манифест и выполняется проверка ссылок, якорей, полной топологии, трёхмерных координат каждого узла, семантической полноты досье, исходных цитат и отсутствия приватных путей и полных книг. Результат записывается в `validation.json`. `npm run check:search` в каталоге `frontend` проверяет словоформы, опечатки, расширение, ранжирование, сохранность цитат и поиск по полному корпусу.

`npm run check:neighborhood` проверяет реальные связи, полноту страниц соседей, неизменность исходного графа и мировые XYZ-координаты. Независимая перспективная проекция проверяет читаемость первого подлёта, отсутствие пересечений с панелями, объём и параллакс при повороте камеры.

Для разработки с автоматическим обновлением интерфейса:

```sh
python scripts/build_site.py
cd frontend
npm ci
npm start
```

Откройте [localhost:4200](http://localhost:4200/). Сначала генерируются данные и Legacy, затем Angular dev server обслуживает их вместе с интерфейсом. Команда `npm start` предназначена для разработки; готовый публикуемый сайт создаётся командой `npm run build`.

GitHub Actions собирает и проверяет сайт для pull request в `main`. После изменений в `main` он также публикует каталог `site/` через GitHub Pages. Workflow можно запустить вручную; публикация разрешена только для ветки `main`.
